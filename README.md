# YT Music v1.5.0 — Made by Studio Mogli

Ad-free background and screen-off YouTube Music player for Android, built by **Studio Mogli** ([studiomogli.com](https://studiomogli.com)).

## What's New in v1.5.0
- **Clean Name:** Renamed to **YT Music** across the launcher and header bar.
- **First-Time & Post-Update Trust Flash Card:** Automatically greets new and updated users with a clear breakdown of ad-free background playback, isolated Google Sign-In, and why the app technically cannot collect personal data.
- **Re-open Anytime:** Added a **Privacy & Security Guarantee** button inside the Studio Mogli card so users can view the trust prompt anytime.
- **Auto-Hidden Update Button:** Stays invisible (`View.GONE`) by default and quietly checks `harekrishna1602/youtube-music` GitHub Releases. Only appears when a newer version is published.
- **Auto GitHub Releases:** Pushing to `main` builds `YTMusic-v1.5.0-StudioMogli.apk` and automatically publishes it to the repository's **Releases** page.
